## 本地原始 observation 边界

`run/` 是被 `.gitignore` 忽略的本地运行目录，包含历史 HTTP 原始 observation、Search v4 paired package、open/sealed 工作表和模型辅助诊断原件。它们体积大且不是主质量发布入口；可提交的客服/capacity curated package 已复制必要的 report、badcase、manifest 和 `SHA256SUMS`。源码暴露审计明确排除该运行目录，避免把同一历史输入在 report/case/badcase 中重复计为源码命中。不要为了“完整”把整个 `run/` 加入 Git，也不要把临时 `.env`、token、服务日志和缓存提交。
