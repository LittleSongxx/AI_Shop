## 客服 HTTP observation

这些包均使用 60 条 `HUMAN_VERIFIED` gold，均声明 `releaseGateEligible=false`。HTTP 执行、行为契约、verifier、延迟和 usage 是运行诊断；答案正确、引用支持和 unsafe 只有独立人工审查后才能进入答案质量报告。

| 包 | 生命周期 | 执行/契约摘要 | provenance | 关键哈希 |
|---|---|---|---|---|
| [`v14`](../../AI_Shop-backend/AI_Shop-agent/evaluation-evidence/benchmarks/customer-service/customer-service-http-v14-20260825/) | `LIVE_EXECUTED_OBSERVATION` / `EXECUTED_PENDING_HUMAN_ANSWER_REVIEW` | 60/60；10 条契约；2 条违例：`019`、`055` | 真实 Provider 执行；source observation 未另存为 package 字段（`null` 是合法 live 口径） | report `53989861835a...d349`；`SHA256SUMS` `d366f934097f...24ae0` |
| [`v20`](../../AI_Shop-backend/AI_Shop-agent/evaluation-evidence/benchmarks/customer-service/customer-service-http-v20-20260825/) | `EXECUTED_PENDING_HUMAN_ANSWER_REVIEW` | 60/60；11/11 契约；0 违例；hard constraint `0`；fixture cleanup `0` | 从已保存 observation 离线重算，Provider 未重跑 | report `10d171bc3393...596d`；source `5a9af0d845d6...1d19`；`SHA256SUMS` `fc9a1b8797c0...05cc` |

v20 runtime 诊断为本地 full-stack P50/P95/P99 `1011.116/2010.016/7268.746 ms`，8 次 Provider call、input/output `17092/833`，费用 `UNPRICED`。这些数字不能改写为生产 SLO、持续吞吐或零成本。

## v20 人工答案审查生命周期

权威链路如下，所有节点均有自己的 `SHA256SUMS`，不可覆盖：

```text
customer-service-http-v20-20260825/report.json
  -> pending-adjudication package (sealed reviewer-a/b, agreement, 4-row template)
  -> adjudicated package (reviewer-c decisions, final-report, badcases)
```

最终指标（分母必须随数值一起阅读）：

| 指标 | 结果 | badcase |
|---|---:|---:|
| 答案正确 | `57/60 = 95.00%` | `014/018/043` |
| 可计分引用支持 | `25/36 = 69.44%` | 11 条：见 final report |
| 转人工适当 | `60/60 = 100%` | 0 |
| unsafe answer rate | `1/60 = 1.67%` | `014` |
| 联合质量 | `49/60 = 81.67%` | 11 条 |

`014` 的无证据退款后果提示是当前最高风险 badcase。v20 与 v13 是不同冻结输出和不同引用 eligible 分母，不能只比较上升项，也不能称严格因果 A/B；所有结果都不外推为 CSAT、FCR 或无人值守客服能力。

## 人工提交文件收口

人工提交文件在校验后只保留在对应的 immutable pending/final evidence package 中。仓库根目录和
`evaluation/datasets/customer_service/` 不再保留相同内容的交接副本或已完成 open 工作区，避免出现多份可编辑主证据。

## 本地原始 observation 边界

`run/` 是被 `.gitignore` 忽略的本地运行目录，包含 v14-v20 原始 observation、open/sealed 工作表和模型辅助诊断原件。它们体积大且不是仓库发布入口；可提交的 curated package 已复制必要的 report、badcase、manifest 和 `SHA256SUMS`。不要为了“完整”把整个 `run/` 加入 Git，也不要把临时 `.env`、token、服务日志和缓存提交。
