# E9 前端真实闭环验证（2026-08-29）

状态：`CONTROLLED_PREPROD_ONLY`。本批把现有 Agent 页面、WebSocket manager、旧版卡片协议
和浏览器 mock 流程收口为可复核前端证据；不把 mock 浏览器结果写成线上可用性或 Web Vitals
SLO。

## 本批收口

- 新增 `agentCardAdapter` typed adapter。`ACTION_CONFIRM` 和 `SUPPORT_CASE_*` 同时接受
  camelCase/snake_case 历史字段，未知字段不透传到渲染层；Action snapshot/status、订单项、
  工单 evidence 均先经过有界归一化。旧 API/事件名保持兼容。
- Agent 对话区使用 `role=log`、中文 label、终态 `role=status/aria-live`；确认卡和工单卡保留
  原生 button 键盘路径，桌面端回复结束后恢复输入框焦点；全局 `prefers-reduced-motion` 关闭
  光标闪烁、过渡和滚动动画。
- WebSocket manager 已有 OPEN barrier、seq/eventId 去重和 terminal reconciliation；本批补上
  token rejection 的 cookie-backed session refresh。刷新失败只结束重连并提示登录，不把断线当成
  业务成功。
- 使用浏览器原生 `PerformanceObserver` 收集 FCP/LCP/CLS/INP/TTFB 到有界内存窗口和
  `aishop:web-vital` 事件，不新增第三方依赖或上传原始用户内容。现有 stream accumulator 仍有
  512 条上限，长会话不会无限增长 reducer 辅助状态。
- 新增 Playwright mock：token 过期→重新建立 WS、可访问对话区，以及取消请求等待服务端权威
  `terminalState` 后再结束。既有 mock 已覆盖乱序/重复/迟到终态和商品点击归因；live Playwright
  仍由外部服务开关控制。
