## 明确边界

- `AISHOP_LIVE_E2E_PAYMENT` 默认关闭；本次没有调用支付宝 sandbox。打开它需要独立支付凭据，不能把本次结果写成下单/支付证据。
- 该用例路径由规则路由到 `SEARCH_PRODUCTS`，不等价于一次 LLM 生成质量评测；客服 E57 包才记录了真实 Provider 调用和人工答案待审状态。
- 单次受控运行不能推出 CTR/CVR/GMV、线上 SLO、用户行为分布或长期归因可靠性；后续仍需预注册 hard-negative/语义 holdout 与人工视觉标签。
