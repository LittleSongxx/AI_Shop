## 与正式门禁的关系

正式 v14 closure 仍为 `EXECUTED_PENDING_INDEPENDENT_HUMAN_REVIEW`，人工审查覆盖 `0/60`，`answerCorrectness`、`citationGroundingSupport` 和 `unsafeAnswerRate` 在正式报告中保持 `null`。只有两位真实独立 reviewer 完成原始 A/B 表、第三位真人完成分歧仲裁后，才可以生成正式 `HUMAN_REVIEWED_ADJUDICATED` evidence。

模型辅助结果暴露的高价值修复点是：退款知识已召回但答案错误降级（`011/057`）、无商品型号时返回裸“服务异常”（`033`）、长时间未发货未升级（`008`）、支付失败状态未澄清或转人工（`024`）、以及缺件请求未实际转接（`055`）。这些可作为下一轮 v15 修复和回放的优先 badcase，但不能从 v14 包中删除或改写。
