### 2.2 RAG 知识

RAG golden 不再使用占位 chunk ID。FAQ 使用稳定的 `faq_<questionId>`，文档使用稳定的
`source + heading`，运行时才映射为带 release/version/chunk 的引用。锁文件同时约束：

- 评测集 SHA-256：`4cd581038cea0503f78a7d092d0e630fd5b874f496beba9c316d5d54d0c36a88`
- 最低知识 release：`5`
- FAQ：`9001` 至 `9006`
- 四份知识文件的 raw 与 normalized SHA-256
- 冻结检索阈值：`0.65`

任一 SHA、release、FAQ 或知识目录不匹配时，runner 必须拒绝运行，不能以降级结果冒充
门禁通过。

### 2.3 会话与搜索评测

`aishop_convo_v1` 是 134 条合成会话的确定性评测，其中 13 条注入订单 fixture、2 条执行
候选选择后的第二轮解析；它不调用真实 LLM、RAG 或业务网络。
`search_relevance_v1` 是基于 47 件目录人工冻结的 30 条分级相关性查询；它要求 keyword
与 vector 两路均有真实召回，缺少标签、目录、ES 或任一路结果时硬失败。

## 4. 当前已实现边界

| 能力 | 当前实现 | 诚实边界 |
|---|---|---|
| AI 客服 | 异步任务账本、分级队列、WebSocket 流式帧、终态持久化、历史恢复、引用展示 | 没有生产并发和客服效率数据 |
| 订单自然语言定位 | 本人订单域内按 ID、状态、时间、商品页指代、taxonomy、品牌型号和规格解析；歧义候选卡；选择事务与状态复核 | 地址、发票、催发货、破损错漏发没有真实写工具；规则实体链接不是训练模型 |
| 人工工单/接管 | 创建、排队、认领、激活、回复、解决、SLA 字段和管理端操作 | 是客服接管流程，不是完整企业 ITSM 平台 |
| RAG | FAQ、文档混合检索、版本目录、引用、拒答阈值和 SHA 门禁 | 没有影子索引式全量回滚或版本灰度 |
| 工具调用 | 结构化意图优先、安全 fallback、必需工具强制补齐、写操作先提案后确认 | 不允许模型绕过 Java 事实源；工具失败会明确降级 |
| 写操作可靠性 | token、业务键、参数指纹、Java 幂等账本、有界对账、人工复核 | 只承诺可审计幂等与复核，不承诺网络分区下 exactly-once |
| 智能导购 | 真实商品召回、过滤、共购/历史偏好、MMR、推荐理由 | 不是训练型推荐模型，不宣称个性化效果提升 |
| 推荐归因 | 曝光/点击事实表、唯一约束、内部批量校验、Cart/Order 最后有效触点 | 仅本地链路验证，无真实 CTR/CVR/GMV 结论 |
| 可观测性 | token、模型/fallback、人民币成本、unpriced token、固定阶段时延、告警契约 | 无真实线上 SLO、告警值班或容量证明 |
| 故障恢复 | Worker lease 接管、发布恢复、重复投递 fencing、checkpoint 失败演练 | 隔离确定性演练不覆盖所有中间件或机房级故障 |

## 5. 明确不实现或留待生产阶段

以下内容不是遗漏包装，也不能写进已完成成果：

1. 生产流量、真实 GMV、CTR/CVR 提升、客服人效和线上 SLO。
2. 大模型预训练、LoRA/全参微调、奖励模型或模型后训练。
3. 训练型召回/排序模型、在线特征平台和大规模 A/B 实验。
4. 多 Agent 协作、端侧推理和专用推理性能优化。
5. 企业级工单平台所需的组织权限、全渠道接入、排班和审计合规体系。
6. 网络分区下的 exactly-once；项目采用幂等账本、fencing、有界对账和人工复核。
7. 真实线上 3% 至 5% 流量回放与 LLM-as-judge 质量运营。

## 6. 已评估的设计取舍

### 6.1 知识全量回滚与灰度

当前知识发布是单索引上的增量写入和 release 切换。完整回滚与按用户灰度需要每次发布建
影子索引、别名原子切换并保留旧代际；这与当前 Spring AI 单索引绑定冲突，属于明确的
生产化重构。单文档 archive 已实现，但不能把它描述为全量版本回滚。

### 6.2 生成质量评测

当前门禁优先选择可冻结、可重复的确定性指标。RAGAS/LLM judge 可以作为辅助观察，但在
没有稳定裁判模型、成本预算和抽样协议前，不把随机 judge 分数冻结为质量真相。

### 6.3 跨会话恢复

`agent_message` 已持久化历史，但产品没有 30 天级“恢复到某个未完成会话”的显式入口。
当前实现支持任务恢复和历史加载，不等同于长期跨会话工作流续接。

## 7. 面试表述约束

- 可以说：“我在本地完整栈用锁定数据把 RAG Recall@10 跑到 0.9167，并让 SHA 漂移硬失败。”
- 可以说：“未知写结果不重放副作用，而是查幂等账本并在边界后转人工复核。”
- 可以说：“推荐点击只有匹配持久化曝光、用户、商品和位置后才会进入订单归因。”
- 不可以说：“系统实现了绝对一次执行”“线上转化率提升”“生产 99.9% 可用”。
- 历史 commit 数字必须标注“当时 commit 记录”，当前结果必须单列为“2026-08-06 复测”。
