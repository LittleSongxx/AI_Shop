# Smarlect 账户、地址与安全说明

## 收货地址管理

登录用户可以查看自己的地址列表，新增、修改和删除收货地址。地址包含收件人、联系电话和详细地址，应在提交订单前检查准确性，不要在备注中填写身份证号、密码或银行卡信息。

## 默认地址

用户可以将一条本人地址设为默认地址。设置新默认地址时，系统会取消该用户其他地址的默认标记。默认地址只是结算时的便捷选择，不会自动改写已经生成的订单。

## 地址归属校验

地址列表按当前登录用户查询，设默认和删除时会检查地址是否属于该用户。下单服务通过“地址 ID + 用户 ID”获取收货信息；地址不存在或不属于下单人时应拒绝建单，不向客户端暴露他人地址内容。

## 下单前确认

提交订单前应确认收件人、手机号和详细地址。建单时系统把当时的收货信息复制到订单物流记录，作为该订单的履约快照。之后修改账户地址簿，不会追溯更改这个订单快照。

## 订单生成后地址有误

订单生成后暂不支持用户直接在订单上替换收货地址。发现地址有误时应尽快联系人工客服，是否能处理取决于当前履约状态；已发货订单不保证能够改址或拦截。

## 账户与订单边界

订单、地址、评价、售后和支付记录都应以登录用户身份为边界查询。客户端提供的用户 ID 不能代替服务端登录态；对不属于当前用户的资源，系统应返回不存在或拒绝访问，不应返回具体业务内容。

## 敏感信息边界

客服排查可能需要订单号，但不应索取登录密码、支付密码、完整证件号或完整银行卡号。AI 助手不应在普通 Trace 或回答中复制完整收件电话和地址；需要用户确认时应优先使用脱敏展示。
